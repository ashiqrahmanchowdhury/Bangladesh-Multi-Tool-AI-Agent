# 🇧🇩 Bangladesh Multi-Tool AI Agent

> **Module 22 Assignment**

A Multi-Tool AI Agent built using **Python**, **LangChain**, **SQLite**, **Pandas**, **Hugging Face Datasets**, and **DuckDuckGo Search** to answer questions related to hospitals, educational institutions, restaurants, and general knowledge in Bangladesh.

---

## 📖 Project Overview

This project demonstrates a Multi-Tool AI Agent capable of routing user queries to different tools based on the query type.

The agent supports:

- Hospital database queries
- Educational institution database queries
- Restaurant database queries
- Web search for general knowledge

---

## ✨ Features

- Hospital Information Query
- Educational Institution Query
- Restaurant Information Query
- Web Search using DuckDuckGo
- Intelligent Query Routing

---

## 🗂️ Datasets

The project uses three Bangladesh datasets converted into SQLite databases:

- Hospitals Database
- Educational Institutions Database
- Restaurants Database

---

## 🛠️ Technologies Used

- Python
- LangChain
- SQLite
- Pandas
- Hugging Face Datasets
- DuckDuckGo Search (DDGS)
